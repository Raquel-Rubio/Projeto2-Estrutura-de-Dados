# **READ ME**

Projeto 2 da matéria Estrutura de Dados

Sistema de gerenciamento de falhas de equipamentos computacionais, programado em C.
O sistema inclui a capacidade de regitrar equipamento, registrar incidente, consultar equipamento e incidente, listar todos os incidentes, excluir um incidente e excluir um equipamento.

Os equipamentos deverão possuir:
 - Código Único de Identificação
 - Nome (Apelido) do Equipamento
 - Lista com o Número Único de Identificação dos incidentes atribuídos a esse equipamento.

Os Incidentes deverão possuir:
 - Número Único de Identificação
 - Código do Equipamento relacionado
 - Nível de Gravidade (de 1-Baixo a 3-Alto)

>[!NOTE]
>Esse projeto tem objetivos puramente educacionais
